# Summary

Let a user work one epic as a project: pick it in the sidebar and see only its work on the board, with progress, while every other filter keeps working.

# Business Context

Once a repository has several epics, the status columns mix all of them and the only hierarchy cue is the `↳ PARENT-ID` link on each card. Finishing an epic means knowing what is left in it, what blocks it, and where new work for it goes.

# Technical Context

The design, including the rejected "Epics column" layout, is in `docs/DESIGN-2026-09-epic-focus.md`. It is viewer-only: no change to `SPEC.md`, the validator or the item format.
