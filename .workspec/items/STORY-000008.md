# Summary

The modal, toast and sidebar controls lack the semantics assistive technology needs, and the create dialog does not submit on Enter. Small, contained fixes.

# Business Context

Keyboard and screen-reader reachability is table stakes for a tool developers keep open all day; PROMPT.md section 9.3 also asks for keyboard support.

# Technical Context

`index.html:40-41` (overlay, toast), `app.js` overlay plumbing, `ui/sidebar.js` selects, `ui/board.js` columns.

# Requirements

- Dialog semantics with focus trap and focus restore.
- Live region for the toast.
- Labels for all form controls.
- Enter-to-submit and required title in the create dialog.

# Implementation Notes

Coordinate with STORY-000013 (keyboard-first navigation) so focus management is built once.
