# Summary

PROMPT.md section 9.3 asks for keyboard navigation; today only Tab, Enter, Escape and Ctrl+S exist. Add board navigation keys, a command palette and a live split Markdown preview.

# Business Context

Developers keep the board open next to an editor; keyboard flow is how they will actually use it.

# Technical Context

Cards already have `tabindex` and `role=button`. Status moves reuse `store.moveItem`. The palette is a new `ui/palette.js` view over the store's filtered items.

# Requirements

- Board key handling with focus tracking per column.
- Palette with fuzzy match on ID and title, plus actions.
- Live preview pane in the editor replacing the Edit/Preview toggle (keep the toggle for narrow layouts).
- Help overlay.

# Implementation Notes

Build focus management once together with STORY-000008.

# Risks

Global key handlers must respect focus in inputs, the raw YAML textarea and the Markdown editor.
